# 🎬 CineFind - Movie Search App

## Project Description

CineFind is a responsive movie search website
built using HTML, CSS, and JavaScript.

Users can search for movies and TV series,
view movie posters, and read detailed
information about their favorite films.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- OMDb API

## Features

- Search movies by title
- Search TV series
- Display movie posters
- Display release year
- View movie information
- View IMDb ratings
- View movie genres
- View cast and directors
- View movie descriptions
- Pagination
- Mobile responsive design
- Error handling

## Project Structure

movie-search-app/
  index.html
  style.css
  script.js
  README.md

## How to Run

1. Download or clone the project.
2. Open the folder in VS Code.
3. Get an API key from:
   https://www.omdbapi.com/apikey.aspx
4. Open script.js.
5. Replace YOUR_OMDB_API_KEY with your API key.
6. Save the file.
7. Open index.html using Live Server.
8. Search for any movie.

## How It Works

The application uses JavaScript to send
requests to the OMDb API.

The API returns movie information in JSON.

JavaScript processes the response and
displays the results on the webpage.

Users can select a movie to view more details.
