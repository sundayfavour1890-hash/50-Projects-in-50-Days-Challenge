# 🛍 ShopEase - E-Commerce Product Page

A modern, responsive E-Commerce Product Page
built with HTML, CSS, and JavaScript.

## Project Overview

ShopEase is a frontend e-commerce project that
demonstrates a modern online shopping experience.

The application allows users to view a product,
select product variations, adjust quantities,
add products to a shopping cart, and calculate
their total price.

## Features

- Responsive navigation bar
- Modern green-and-white design
- Interactive product image gallery
- Product information and description
- Product price and discount
- Color selection
- Size selection
- Quantity selector
- Add to cart functionality
- Shopping cart drawer
- Remove products from cart
- Cart item counter
- Automatic subtotal calculation
- Customer review section
- Related products section
- Local storage support
- Mobile-responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6
- Browser Local Storage
- DOM Manipulation

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Make sure all four files are present.
4. Right-click index.html.
5. Select "Open with Live Server".
6. View the product details.
7. Select your preferred color and size.
8. Choose the product quantity.
9. Click "Add to Cart".
10. Open the cart to view your items.

## How It Works

1. HTML creates the product page structure.
2. CSS styles the product layout.
3. JavaScript handles user interactions.
4. Users can select product variations.
5. Products are added to the shopping cart.
6. JavaScript calculates the cart subtotal.
7. Local storage saves the cart data.
