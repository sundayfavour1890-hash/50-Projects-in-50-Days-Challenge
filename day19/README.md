# Currency Converter Interface

A responsive currency converter interface built with HTML and CSS.

## Run

Place `index.html` and `style.css` in the same folder.
Open `index.html` in a browser.

## Current behavior

You can enter an amount and select currencies, but this version does not
calculate a result. HTML and CSS cannot perform the required conversion
or retrieve current exchange rates. A working converter needs JavaScript
and an exchange-rate data source.
