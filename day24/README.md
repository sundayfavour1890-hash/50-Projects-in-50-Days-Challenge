# 🍃 Recipe Finder

Recipe Finder is a responsive website that allows users
to discover delicious meals from around the world.

The website uses a beautiful green and white design.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- TheMealDB REST API
- Browser Local Storage

## Features

1. Search for recipes by name.
2. View food images.
3. Browse recipes by category.
4. View detailed cooking instructions.
5. See ingredients and measurements.
6. Watch cooking videos when available.
7. Discover random recipes.
8. Save and remove favorite recipes.
9. Responsive design for mobile and desktop.
10. Simple green and white user interface.

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension (optional).
4. Right-click index.html.
5. Select "Open with Live Server".
6. Search for your favorite food.

## API

This project uses TheMealDB public API.

API Website:
https://www.themealdb.com/api.php

Example:
https://www.themealdb.com/api/json/v1/1/search.php?s=chicken

An internet connection is required to fetch recipes.

## Local Storage

Favorite recipes are saved in the user's browser
using localStorage.

Favorites remain saved after refreshing the page
on the same browser, unless browser storage is cleared.
