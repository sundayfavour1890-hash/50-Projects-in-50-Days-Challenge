# Day 03 — Simple Login Form

A responsive login form made with HTML and CSS.

## Files

- `index.html` contains the form.
- `style.css` controls its appearance.

## How to view it

Open index.html in your browser. If you use the Live Server extension in VS Code, you can right-click `index.html` and select **Open with Live Server**.

## What I learned

- A <label> connects to an input when its `for` value matches the input's `id`.
- `type="email"` asks for an email address.
- `type="password"` hides the password as it is typed.
- `display: flex` on `.container` helps center the form on the page.
