# 💬 ChatFlow - Chat Application UI

A modern and responsive Chat Application UI built
with HTML, CSS, and JavaScript.

## Project Overview

ChatFlow is a frontend messaging application
designed to demonstrate an interactive chat
interface.

The application allows users to select contacts,
send messages, receive simulated automatic
replies, search conversations, and switch
between light and dark themes.

This is a frontend demonstration, not a
real-time messaging service.

## Features

- Modern messaging interface
- Green-and-white design
- Contact list
- Profile avatars
- Send messages
- Simulated automatic replies
- Message timestamps
- Search contacts
- Emoji picker
- Online and offline status
- Unread message indicators
- Dark mode
- Mobile-responsive layout
- Local storage support
- Delete conversations

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6

- DOM Manipulation

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Ensure all four files are present.
4. Right-click index.html.
5. Select "Open with Live Server".
6. Choose a contact from the sidebar.
7. Type a message and click Send.

## How It Works

1. The application displays sample contacts.
2. Users select a contact.
3. JavaScript loads the conversation.
4. Users type and send messages.
5. A simulated automatic reply is generated.
6. Messages are saved in browser local storage.
7. Users can switch between conversations.

## Important Note

ChatFlow is a frontend-only demonstration.

Messages are not delivered to real people.

No backend server, authentication system,
or real-time database is included.

To build a real messaging application,
additional technologies are required.

Examples include:

- Node.js
- Express.js
- Socket.IO
- Firebase
- Supabase
