# GitHub Profile Finder

A responsive web application that allows users
to search and view public GitHub profiles.

## Features

1. Search GitHub users by username.
2. Display profile pictures.
3. Show names and GitHub usernames.
4. Display user biographies.
5. Show public repository counts.
6. Display followers and following.
7. Show location and company.
8. Display personal website links.
9. View the latest five repositories.
10. Open profiles directly on GitHub.
11. Handle invalid usernames.
12. Responsive mobile-friendly interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub REST API

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html in your browser.
4. Enter a GitHub username.
5. Click the Search button.
6. View the GitHub profile information.

## API

This project uses the public GitHub REST API.

https://api.github.com/users/USERNAME

No API key is required for basic public searches.

GitHub applies rate limits to unauthenticated
API requests.
