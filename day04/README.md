# Day 04 - Calculator

## Description

A simple and responsive calculator built as part of my **50 Projects in 50 Days Challenge**.

The calculator can perform basic mathematical operations such as addition, subtraction, multiplication, division, and percentage calculations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal numbers
- Clear button
- Delete button
- Responsive design

## Files

- `index.html` - Contains the calculator structure and calculation logic.
- `style.css` - Controls the design, layout, and responsiveness.
- `README.md` - Contains information about the project.

## How to View It

Open `index.html` in your browser.

If you are using the Live Server extension in VS Code:

1. Open `index.html`
2. Right-click inside the file
3. Select **Open with Live Server**
