GOOD TO KNOW

Little questions,
clear answers.

Do I need an account?

No. The sample checklist is a simple HTML and CSS page you can open in a browser.

Are my tasks saved?

No. The current checklist uses HTML and CSS only, so checkbox changes reset when you reload the page.

Can I make it my own?

Yes. Edit the task text in the checklist's HTML file and customize its colors in the CSS file.
