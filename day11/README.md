# Weather App

A responsive weather app built with HTML, CSS, and JavaScript.

## Features

- Search for a city
- View current temperature and weather conditions
- View feels-like temperature, humidity, and wind speed
- View a three day forecast
- See a helpful message when a city cannot be found

## How to run

1. Keep `index.html` and `style.css` in the same folder.
2. Open `index.html` in a browser.
3. Search for a city.

An internet connection is required to load weather data.

## Weather data

Location search and forecasts are provided by [Open-Meteo](https://open-meteo.com/).
