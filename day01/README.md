# Day 01 - Personal Portfolio Website

This is my Day 1 project for the **50 Days Coding Challenge**.

I created a personal portfolio website using HTML and CSS.

## About the Project

The website introduces me as an aspiring web developer and provides information about my skills and projects.

The portfolio contains:

- Home section
- About section
- Skills section
- Projects section
- Contact section
- Responsive mobile design

## Technologies Used

- HTML5
- CSS3

## What I Learned

During this project, I practiced:

- Creating an HTML page structure
- Using semantic HTML elements
- Linking an external CSS file
- Flexbox
- CSS Grid
- Hover effects
- Responsive design
- Media queries
- Navigation with section links
