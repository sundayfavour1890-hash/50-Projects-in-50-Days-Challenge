# Today — To-Do List

A simple, responsive to-do list made with HTML and CSS only.

## Run

Keep `index.html` and `style.css` in the same folder, then open `index.html` in a browser. No installation is needed.

## Customize

Edit the text inside each `<span>` in `index.html` to change a task. Copy a `<li>...</li>` line to add another task, or remove one to delete a task. Adjust colors and spacing in `style.css`.

Checkboxes can be marked complete while the page is open. Because this project uses no JavaScript or backend, changes are not saved after a reload.
