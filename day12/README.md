# Expense Tracker

A simple expense tracker built with HTML, CSS, and JavaScript.

## Features

- Add expenses with a description, amount, date, and category
- View total spending
- Filter expenses by category
- Delete expenses
- Keep expenses after refreshing the page using browser local storage
- Responsive layout for phones and computers

## How to run

1. Keep `index.html` and `style.css` in the same folder.
2. Open `index.html` in a browser.
3. Add your expenses using the form.

No account or API key is required.

## Note

Expenses are saved in the browser on the current device. Clearing browser
site data or switching browsers will remove or hide those saved entries.
