# 🛒 ShopCart - Shopping Cart Application

A modern and responsive Shopping Cart Application
built using HTML, CSS, and JavaScript.

## Project Description

ShopCart is a frontend e-commerce application
that allows users to browse products, add items
to a shopping cart, manage quantities, apply
discount coupons, and calculate their total cost.

The application uses browser local storage
to save shopping cart information.

## Features

- Responsive green-and-white interface
- Product catalog
- Product images
- Add products to cart
- Increase product quantity
- Decrease product quantity
- Remove individual products
- Clear entire cart
- Automatic subtotal calculation
- Shipping fee calculation
- Coupon discount system
- Cart item counter
- Local storage support
- Demo checkout
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6
- DOM Manipulation
- Browser Local Storage

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Make sure all four files are present.
4. Right-click index.html.
5. Select "Open with Live Server".
6. Browse the available products.
7. Click "Add to Cart".
8. Manage your cart quantities.
9. Apply a coupon code.
10. View your order total.

## Coupon Code

Coupon: SAVE10

Discount: 10% off the product subtotal.

## Shipping Rules

Orders below $100:
$10 shipping fee.

Orders of $100 or more:
Free shipping.

Empty carts:
No shipping charge.

## How It Works

1. JavaScript displays the product catalog.
2. Users add products to their shopping cart.
3. Cart data is stored in browser local storage.
4. Users can increase or decrease quantities.
5. JavaScript automatically updates totals.
6. Coupon codes reduce the product subtotal.
7. Shipping is calculated automatically.
8. Users can remove products or clear the cart.
