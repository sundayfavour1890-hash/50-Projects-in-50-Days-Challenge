# Notes App

A simple notes app built with HTML, CSS, and JavaScript.

## Features

- Create notes with a title and content
- Edit existing notes
- Delete notes
- Search notes by title or content
- Save notes in the browser using local storage
- Responsive layout for phones and computers

## How to run

1. Keep `index.html` and `style.css` in the same folder.
2. Open `index.html` in your browser.
3. Create your first note.

No account or internet connection is required.

## Storage

Notes are stored in the browser on the current device. Clearing browser
site data or using another browser will not carry your notes over.
