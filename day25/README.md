# 📖 WordWise Dictionary App

A modern, responsive Dictionary Application built using
HTML, CSS, and JavaScript.

## Project Overview

WordWise allows users to search for English words,
discover definitions, listen to pronunciations,
explore synonyms, and improve their vocabulary.

## Features

- Search English words
- View word meanings
- Display phonetic pronunciation
- Listen to word audio
- View example sentences when available
- Explore synonyms
- Save favorite words
- Track recent searches
- Clear saved words and history
- Responsive green-and-white interface
- Error handling for invalid words

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Free Dictionary API
- Browser Local Storage

## API Used

Free Dictionary API

https://dictionaryapi.dev/

API endpoint:

https://api.dictionaryapi.dev/api/v2/entries/en/hello

No API key is required.

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Make sure all four files are in the same folder.
4. Open index.html using Live Server.
5. Type a word in the search box.
6. Click Search to view its definition.

An internet connection is required for dictionary
searches.

## How It Works

1. The user enters a word.
2. JavaScript sends a request to the Dictionary API.
3. The API returns information about the word.
4. JavaScript displays the results.
5. Favorite words and search history are stored
   locally in the browser.
