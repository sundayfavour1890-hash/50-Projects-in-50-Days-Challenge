# Form Validation System

A form built with HTML and CSS. The browser checks that:

- All fields are filled in.
- The name has at least 2 characters.
- The email has a valid email format.
- The password has at least 8 characters.
- The terms checkbox is selected.

## Run

Keep `index.html` and `style.css` in the same folder, then open
`index.html` in a browser.

## Limitation

This is a front-end demonstration. It does not create accounts or save
submitted information. A real account system also needs a server to
validate submissions securely and store passwords safely.
