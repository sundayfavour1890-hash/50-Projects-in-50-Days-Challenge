# Counter App — 50 Days Challenge

A responsive counter app built with HTML, CSS, and vanilla JavaScript for Day 01 of the 50 Days Challenge.

## Run it

Put all four files in the same folder and open `index.html` in a browser. No installation is needed.

## Controls

- Click **+** to increase the count.
- Click **−** to decrease the count.
- Click **Reset** to return to zero.
- Press the **right** or **left** arrow key to change the count.

The count is saved in the browser and remains after a refresh when browser storage is available.
