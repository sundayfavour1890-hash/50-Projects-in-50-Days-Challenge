# BMI Calculator

A responsive BMI calculator built with HTML, CSS, and JavaScript.

## Features

- Calculate BMI using centimetres and kilograms
- Calculate BMI using feet, inches, and pounds
- Display the BMI value and adult BMI category
- Validate height and weight inputs

## How to run

1. Keep `index.html` and `style.css` in the same folder.
2. Open `index.html` in a browser.
3. Select your units, enter your height and weight, and click **Calculate BMI**.

No account or internet connection is required.

## Calculation

BMI = weight in kilograms ÷ (height in metres × height in metres)

The app converts imperial measurements to metric units before calculating.

## Important

The categories shown are for adults aged 20 and older. BMI is a screening
measure, not a diagnosis. It does not directly measure body composition.
For children and teens, BMI must be interpreted using age and sex specific
growth charts.

Category reference: https://www.cdc.gov/bmi/adult-calculator/bmi-categories.html
