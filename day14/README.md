# Password Generator

A password generator built with HTML, CSS, and JavaScript.

## Features

- Choose a password length from 8 to 32 characters
- Include uppercase letters, lowercase letters, numbers, and symbols
- Guarantee at least one character from each selected group
- Generate passwords using the browser's cryptographic random generator
- Copy a password to the clipboard

## How to run

1. Keep `index.html` and `style.css` in the same folder.
2. Open `index.html` in a modern browser.
3. Choose your options and click **Generate password**.
4. Click **Copy** to copy the result.

If the browser blocks clipboard access, select the password and press
**Ctrl+C** (or **Cmd+C** on a Mac).

## Privacy

The app runs in your browser. It does not save or send generated passwords
to a server.
