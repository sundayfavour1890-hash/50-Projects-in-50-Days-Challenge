# 🎓 EduTrack - Student Management Dashboard

A modern and responsive Student Management
Dashboard built with HTML, CSS, and JavaScript.

## Project Overview

EduTrack is a frontend student management
application designed to help organize student
records, attendance, and academic grades.

The dashboard provides a simple interface for
managing student information and viewing
academic statistics.

## Features

- Responsive dashboard layout
- Green-and-white design
- Sidebar navigation
- Student registration
- Add new students
- Edit student information
- Delete student records
- Search students
- Filter students by class
- Student statistics
- Attendance tracking by date
- Grade management
- Academic performance chart
- Recently added students
- CSV export
- Browser local storage
- Mobile-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6
- DOM Manipulation
- Browser Local Storage
- Blob API for CSV export

## How to Run

1. Download or clone the project.
2. Open the folder in VS Code.
3. Ensure all four files are present.
4. Right-click index.html.
5. Select "Open with Live Server".
6. Explore the dashboard.
7. Register and manage students.
8. Update grades and attendance.

## How It Works

1. HTML creates the dashboard structure.
2. CSS styles the interface.
3. JavaScript manages application functionality.
4. Student records are saved in local storage.
5. Grades and attendance are updated interactively.
6. Statistics are calculated automatically.
7. Student records can be exported to CSV.

## Student Management

Administrators can:

- Register students
- Edit student details
- Delete student records
- Search for students
- Filter students by class
- Change student status

## Attendance Management

Attendance is recorded for a selected date.

Available statuses:

- Present
- Absent
- Late
- Not Marked

The dashboard calculates attendance rate
using marked attendance records.

Present and Late both count toward
the attendance rate.

## Grade Management

Grades are entered as scores from 0 to 100.

Grade ranges:

A: 70-100
B: 60-69
C: 50-59
D: 45-49
E: 40-44
F: 0-39

The dashboard displays average scores
and a grade distribution chart.

## Export Feature

Student records can be exported as a CSV file.

The exported file includes:

- Student ID
- Full Name
- Email
- Class
- Age
- Status
- Grade

## Important Note

This is a frontend demonstration project.

It does not include:

- Real user authentication
- A backend database
- Multi-user synchronization
- Cloud backup
- Role-based access control
- Server-side security

Data is stored only in the current browser.

Do not use real student personal information
in this demonstration.
