# NewsHub - News Application

## Project Overview

NewsHub is a modern and responsive news application
built using HTML, CSS, and JavaScript.

The application allows users to read the latest news,
search for articles, and browse different news categories.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- The Guardian Open Platform API

## Features

1. Latest news headlines
2. Search functionality
3. News category filtering
4. Article images and descriptions
5. Publication dates
6. Read More links
7. Dark and light mode
8. Responsive design
9. Load More functionality
10. Error handling

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Right-click index.html.
5. Select "Open with Live Server".
6. The news application will open in your browser.

## API

The application uses The Guardian Open Platform API.

API Endpoint:
https://content.guardianapis.com/search

The project uses the public test API key for learning
and demonstration purposes.

The test key has usage limits and is not intended
for production applications.
