# Search Application

## Project Description

Search Application is a simple and responsive
web application built using HTML and CSS.

It allows users to search for information
on the internet using Google Search.

## Features

- Simple and attractive user interface
- Responsive design for mobile and desktop
- Search input field
- Search button
- Google Search integration
- Easy to use

## Technologies Used

- HTML5
- CSS3
- Google Search

## Project Structure

search-application/
│
├── index.html
├── style.css
└── README.md

## How to Run the Application

1. Download or clone the project.
2. Open the project folder.
3. Locate the index.html file.
4. Open index.html in your web browser.
5. Enter your search query.
6. Click the Search button.
7. Google will display the search results.

## How It Works

The application contains a search form.

When a user enters a search query and clicks
the Search button, the query is sent to
Google Search.

Google then displays results related
to the user's search.
